# Аудит портала и парсеров — 21.10.2026

## Результат

- Основные публичные страницы, каталог материалов, `robots.txt` и `sitemap.xml` отвечают HTTP 200.
- Раздел Life-OS отвечает HTTP 401 без учётных данных — это штатная Basic Auth-защита, а не отказ приложения.
- Локальный регрессионный набор: 179 тестов пройдены.
- API Рубрикатора Минздрава доступен: первая тестовая страница получена, источник сообщает 774 записи до профильной фильтрации.
- RSS SecurityLab доступны: `news` — 100 записей, `vulnerabilities` — 25, `analytics` — 10; `software` вернул валидный пустой RSS.
- Контракт MIT → Life-OS и защита ingest-токеном покрыты тестами; внешний n8n-сценарий требует отдельной проверки в самом n8n.

## Найденный разрыв

Еженедельный workflow автоматически получал только российские рекомендации из API Минздрава. Международные карточки сохранялись в статическом реестре или приходили через внешний n8n, поэтому новое руководство AAO-HNSF не могло быть обнаружено автоматически.

## Исправление

1. В белый список официальных источников добавлен AAO-HNSF (`entnet.org`).
2. Добавлен узкий адаптер официального каталога AAO-HNSF.
3. Адаптер принимает только заранее разрешённые клинические руководства и не использует пресс-релизы производителей как клинический источник.
4. В еженедельный workflow включена синхронизация AAO-HNSF.
5. В реестр добавлена карточка `Clinical Practice Guideline: Tinnitus Update`, DOI `10.1002/ohn.70417`, официальная дата публикации 12.10.2026.
6. Создана Obsidian-карточка со статусом `needs-human-review`; медицинская интерпретация не публикуется автоматически.
7. Добавлены регрессионные тесты на успешное распознавание официальной карточки и отклонение рекламного пресс-релиза.

## Контроль качества

- При изменении вёрстки AAO-HNSF адаптер не угадывает дату и не создаёт сомнительную карточку.
- При временной недоступности источника ранее подтверждённые карточки не удаляются.
- Ссылки принимаются только с разрешённых официальных доменов по HTTPS.
- Полный текст руководства не копируется на портал; публикуется библиографическая карточка и ссылка на первоисточник.
