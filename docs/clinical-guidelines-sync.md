# ДИС Монитор клинических рекомендаций

Модуль автоматически добавляет на портал библиографические карточки официальных
клинических рекомендаций по неврологии и нейрохирургии. Оригинальный документ
остаётся в официальном источнике; портал хранит название, организацию, дату,
версию, коды МКБ и ссылку.

## Российский контур

Источник: `https://cr.minzdrav.gov.ru/`.

Сервер получает действующие рекомендации из официального JSON-метода, оставляет
документы, одобренные Научно-практическим советом, и отбирает профильные записи
по названию, разработчикам и кодам МКБ. Повторный запуск не создаёт дубли:
ключом служит сочетание источника и `CodeVersion`.

### Запуск из n8n

1. `Schedule Trigger`: ежедневно, например в 06:30 по Москве.
2. `HTTP Request`: `POST https://st8dom.ru/api/clinical-guidelines/sync/minzdrav/?page=1&page_size=25`.
3. Заголовок: `Authorization: Bearer {{$env.GUIDELINES_SYNC_TOKEN}}`.
4. `IF`: проверить, что `ok = true`.
5. При ошибке отправить владельцу уведомление; при успехе записать статистику
   `scanned`, `matched`, `created`, `updated`, `unchanged`, `total_pages`.

Ежедневно достаточно проверять первую страницу: официальный API сортирует её от
новых документов к старым. Для первоначального наполнения n8n проходит страницы
от `1` до `total_pages` последовательными запросами. Маленькие страницы нужны,
потому что официальный сервер иногда медленно формирует большую выгрузку.

Одинаковое значение `GUIDELINES_SYNC_TOKEN` задаётся в окружении сайта и n8n.
Секрет нельзя хранить в workflow в открытом виде или коммитить в Git.

## Международный контур

Адаптер источника в n8n получает метаданные с официальной страницы организации
и отправляет каждую карточку в:

`POST https://st8dom.ru/api/clinical-guidelines/import/`

Разрешённые источники: AAN, EAN, ESO, CNS, AANS, NICE, WHO и AHA/ASA. Сервер
проверяет HTTPS и домен по белому списку; ссылка с постороннего домена будет
отклонена.

Пример пакета:

```json
{
  "source_key": "ean",
  "external_id": "ean-guideline-2026-001",
  "title": "Название клинической рекомендации",
  "organization": "European Academy of Neurology",
  "version": "2026",
  "codes": "G20",
  "specialties": "Neurology",
  "url": "https://www.ean.org/official-guideline-page",
  "published_on": "2026-09-17",
  "status": "active"
}
```

## Правила безопасности

- карточка с неофициального домена не принимается;
- повторный пакет обновляет существующую запись, а не создаёт дубль;
- PDF не копируется без подтверждённого права на распространение;
- AI не меняет текст официального документа;
- разбор доказательств и практические выводы публикуются только после проверки
  Степановым Д.А.;
- при недоступности источника старые карточки не удаляются автоматически.

## Проверка после развёртывания

1. Открыть `/clinical-guidelines/`.
2. Запустить российский workflow вручную.
3. Убедиться, что появились только профильные карточки и ссылки ведут на
   `cr.minzdrav.gov.ru`.
4. Повторить запуск и проверить, что `created = 0`, а записи не продублировались.
5. Перед включением расписания проверить уведомление об ошибке источника.
