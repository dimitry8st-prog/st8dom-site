# Идея: воспроизведение научных работ AI-агентом

## Решение на первом этапе

Не внедрять в публичный портал. Функция наподобие alphaXiv AutoResearch запускает
агента, который пишет код и проводит вычислительные эксперименты. Это не заменяет
рецензирование и не подтверждает медицинскую применимость результата.

## Что можно использовать раньше

- связанные документы по теме;
- готовое библиографическое описание источника;
- версии и история обновлений материала;
- аудиоверсия проверенной публикации.

## Условие возврата к идее

Вернуться после накопления 30–50 проверенных публикаций и только для технических
AI-работ. Нужны изолированная среда исполнения, лимиты ресурсов, журнал эксперимента,
проверка лицензий и обязательная экспертная оценка результата. Для медицинских
выводов автоматическое «воспроизведение» не является основанием для публикации.
