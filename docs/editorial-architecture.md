# Редакционная архитектура портала ДИС

## Реализованный вертикальный срез

Публичный сайт и редакционная система используют одну базу, но разные правила
доступа. Публичные маршруты читают только материалы со статусом `published` и
заполненной датой публикации. Черновик открывается только авторизованному
администратору через отдельный маршрут предпросмотра с `noindex,nofollow`.

```text
Админка → черновик → предпросмотр → проверка полей → публикация
                                                   ↓
Главная → каталог материалов → статья → источники → связанные материалы
```

## Сущности

- `Article` — текст, раздел, тип, статус, автор, даты и медицинская проверка.
- `Rubric` — редакционная рубрика внутри одного из четырёх разделов.
- `Tag` — тема для фильтрации и связей.
- `ArticleSource` — название и исходный URL проверяемого источника.

Статьи не хранятся в `cases.py` и не смешиваются с карточками проектов.

## Безопасная публикация

Обычный материал нельзя опубликовать без заголовка, постоянного адреса,
описания, текста, раздела, рубрики, типа, автора и хотя бы одного тега.
Медицинский материал дополнительно требует:

1. хотя бы один источник;
2. медицинского редактора;
3. дату проверки;
4. публичное предупреждение о границах применения.

Life-OS в будущем сможет создавать только `draft`. Переход в `published`
выполняется отдельным действием администратора после проверки.

## Публичные маршруты

- `/materials/` — каталог и фильтры;
- `/materials/<slug>/` — опубликованная статья;
- `/admin/articles/` — редакционный список;
- `/admin/articles/<id>/preview/` — закрытый предпросмотр.

## Следующие этапы по ТЗ

1. Формализованный JSON/Markdown-импорт Life-OS с идентификатором пакета и
   защитой от повторной загрузки.
2. Единый полнотекстовый поиск по публикациям, тегам и проектам.
3. Подписка с подтверждением адреса и выбором тем.
4. Формирование коротких анонсов для Telegram, VK и email после публикации.
5. Миграции, резервное копирование и документированный откат.

Персональные рекомендации, кабинеты читателей, аудио и автоисследование не
входят в первый этап.
