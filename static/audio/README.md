`static/audio/bach-prelude-c-major-bwv846.mp3`

Источник: [Kimiko Ishizaka — Prelude No. 1 in C major, BWV 846](https://commons.wikimedia.org/wiki/File:Kimiko_Ishizaka_-_Bach_-_Well-Tempered_Clavier,_Book_1_-_01_Prelude_No._1_in_C_major,_BWV_846.ogg) (Wikimedia Commons, [welltemperedclavier.org](http://welltemperedclavier.org)).  
Лицензия записи: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Композиция Баха — общественное достояние.

## Какой файл класть

Спокойная инструментальная запись **«Прелюдии до мажор» Иоганна Себастьяна Баха, BWV 846**.

Подходит только запись с лицензией:

- Public Domain
- CC0
- коммерческая Royalty Free, которая явно разрешает использование на сайте и в рекламном ролике

Не загружайте современную защищённую запись без разрешения правообладателя.

Проверенные отправные точки (проверьте лицензию конкретной дорожки перед копированием):

- [Musopen — Prelude and Fugue in C major, BWV 846](https://musopen.org/music/4082-prelude-and-fugue-in-c-major-bwv-846/)
- [Wikimedia Commons — категории записей BWV 846](https://commons.wikimedia.org/wiki/Category:BWV_846)

После загрузки переименуйте файл точно так:

`bach-prelude-c-major-bwv846.mp3`

Плеер на сайте работает и без этого файла: музыка просто не запускается, ошибки нет.

## Сведение

Готовый MP4 лучше собирать уже со сведённой дорожкой:

- музыка 8–12% относительно голоса;
- на ключевых репликах 6–8%;
- появление 1 с, затухание 2 с;
- без резких звуковых эффектов.

Если кладёте только этот MP3, плеер сам держит тихую громкость и плавные края.
