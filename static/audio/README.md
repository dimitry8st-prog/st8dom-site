# Озвучка проектов без музыкального сопровождения

Плееры страниц кейсов и портфолио используют отдельные файлы `<имя-видео>-voice-only.mp3`. Встроенный звук MP4 выключен. Отдельная кнопка управляет озвучкой; пауза, перемотка и скорость синхронизированы с видео.

Для 11 существующих роликов голос выделен из исходной звуковой дорожки моделью Demucs htdemucs. Silero VAD выделяет речевые фрагменты; вне них фон заглушён с плавными краями. Уровень нормализован до -18 LUFS, MP3: mono, 24 kHz, 64 kbps. Автоматическое разделение может давать небольшие артефакты речи и остатки фона; исходные MP4 сохранены.

Проверены наличие речи, длительность всех дорожек и распознавание первых 18 секунд каждого файла. Плеер проверен на воспроизведение, паузу, перемотку, изменение скорости, выключение озвучки и смену ролика.

FAQ использует прежний отдельный файл `faq-assistant-vo.mp3` и субтитры `static/subtitles/faq-assistant-ru.vtt`. Музыкальный файл `bach-prelude-c-major-bwv846.mp3` больше не подключён к плеерам. Сохранённая исходная запись: Kimiko Ishizaka, BWV 846, CC0; https://commons.wikimedia.org/wiki/File:Kimiko_Ishizaka_-_Bach_-_Well-Tempered_Clavier,_Book_1_-_01_Prelude_No._1_in_C_major,_BWV_846.ogg

Новые ролики готовьте с отдельной голосовой дорожкой без музыки.

При `waiting` видео отдельная озвучка ставится на паузу, при `playing` продолжает с позиции видео. Это предотвращает уход голоса вперёд и повторение слов при обратной синхронизации во время буферизации. Прерванный старый запрос `Audio.play()` после паузы, перемотки или смены ролика не отключает новую озвучку. Регрессионная проверка: `node tests/test_project_narration.js`.

## KnightCat: новая озвучка, 3 октября 2026

Для `knightcat-content-factory-16x9` отделённая от музыки дорожка заменена новой русской озвучкой (DmitryNeural). Четыре коротких блока без повторов, одинаковый темп, паузы между сценами. Название произносится «Найт Кэт». MP3: mono, 48 kHz, 128 kbps; нормализация до -18 LUFS. Общая длительность сохранена: 42 секунды.

В MP4 также заменена встроенная дорожка: скачанный ролик содержит ту же речь без музыки. Веб-плеер по-прежнему использует только отдельный MP3, поэтому две дорожки одновременно не звучат. Субтитры совпадают с новой речью. Версия `voice-v2-20261003` в ссылках предотвращает использование старого файла из кэша.

Текст:

- Найт Кэт — контент-завод в Телеграме. Начните с идеи для публикации.
- Бот готовит текст и изображение. Черновик приходит в один диалог.
- На экране — три примера контента. Разные темы, единый маршрут подготовки.
- Вы проверяете факты и формулировки. Отправка материала — после вашего подтверждения.

Каждый блок проверен повторным распознаванием: все предложения восстановлены без потери слов; NightCat распознан как название. Изображение видео сохранено без перекодирования. Прошлая версия остаётся в истории Git.
