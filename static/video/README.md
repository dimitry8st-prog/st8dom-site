# Видео ролика FAQ-ассистента

Ожидаемые файлы:

- `faq-assistant-demo.mp4` — 1920×1080, 35–45 секунд, H.264, оптимизация для веба
- `faq-assistant-demo-vertical.mp4` — 1080×1920, тот же монтаж
- `faq-assistant-poster.webp` — постер 1920×1080 (уже в репозитории)

## Если MP4 ещё нет

Страница кейса показывает HTML-демонстрацию с тем же сценарием, постером, субтитрами и расшифровкой. Не кладите пустые или случайные бинарные файлы «для галочки».

## Требования к готовому ролику

- стиль: минималистичный, деловой, технологичный;
- цвета: тёмно-синий / индиго, оранжевые акценты, белый текст;
- без роботов, неона, космоса и визуальной «AI-магии»;
- интерфейс как у реального бизнес-инструмента;
- спокойная мужская озвучка, 135–145 слов в минуту, нейтральное русское произношение;
- `preload` на сайте: `none` / `metadata`, без автовоспроизведения со звуком.

Текст озвучки — в README корня репозитория и в расшифровке на странице кейса.
