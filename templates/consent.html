Согласие на обработку персональных данных

Отмечая поле согласия на форме, вы даёте Дмитрию Степанову согласие на обработку указанных вами данных, чтобы связаться с вами по заявке.

Состав данных

Имя, email, телефон и компания (если заполнены), тема, текст сообщения, факт согласия и хэш IP для антиспама.

Действия с данными

Сбор, запись в базу сайта, чтение администратором, удаление по вашей просьбе, передача в служебный Telegram оператора — только если этот канал включён в настройках сервера.

Отзыв

Согласие можно отозвать письмом на {{ email_address }}. После отзыва заявка удаляется из базы, если нет иной законной обязанности её сохранить.

Подробности хранения — в политике конфиденциальности.
