# ДИС · клинические рекомендации

Эту папку можно открыть в Obsidian как отдельный Vault. Автоматизация создаёт
в `Клинические рекомендации/Входящие` структурированные Markdown‑заметки из
официального реестра Минздрава.

Оригиналы документов не копируются в GitHub: каждая заметка содержит ссылку на
официальный источник. Клинические выводы и допуск материала в RAG выполняются
только после проверки Степановым Д.А.
